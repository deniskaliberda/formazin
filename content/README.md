# Website-Texte zum Bearbeiten (für das Büro)

In diesem Ordner liegen alle Texte der neuen Leistungs- und Wissensseiten als
einfache Textdateien (`.md`). **Diese Dateien sind die einzige Stelle, an der
Texte geändert werden** — die Website baut sich daraus automatisch.

## So bearbeitet ihr eine Seite

1. Datei öffnen (jeder Texteditor genügt, auch Word → aber als .md/Text speichern).
2. Text ändern. Fertig. Denis spielt die Änderung ein und ihr seht sie in der Vorschau.

## Was die Zeichen bedeuten

| Zeichen | Bedeutung |
|---|---|
| Block zwischen `---` ganz oben | Seiteneinstellungen (Titel bei Google, Beschreibung). Gern ändern, aber kurz halten. |
| Erster Absatz nach dem `---`-Block | Die Kurz-Antwort-Box oben auf der Seite (2–3 Sätze). |
| `## Überschrift` | Abschnitt auf der Seite |
| `### Unterüberschrift` | Schritt im Ablauf bzw. eine Frage im FAQ-Bereich |
| `- Punkt` | Aufzählungspunkt |
| `**Wort**` | fett |
| `<!-- ... -->` | interne Notiz — erscheint NIE auf der Website |

## Ordner

- `leistungen/` — die 5 Leistungsseiten (Tragwerksplanung, Brandschutz, Architektur, Generalplanung, Wärmeschutz)
- `wissen/` — Ratgeber-Artikel
- `team/` — die Kurzprofile für die Über-uns-Seite (eine Datei pro Person)

## Drei Regeln

1. **Keine Honorare/Preise eintragen**, solange sie nicht ausdrücklich
   freigegeben sind. Externe Richtwerte immer als solche kennzeichnen.
2. **Nichts behaupten, was formal nicht belegt ist** (z. B. „Prüfingenieur"
   oder Brandschutz-Nachweisberechtigung ab Gebäudeklasse 4) — erst klären,
   dann schreiben. Die Notizen `<!-- ... -->` in den Dateien markieren genau
   diese offenen Punkte.
3. Fragen oder unsicher? Einfach als Notiz `<!-- Frage: ... -->` in die Datei
   schreiben — Denis sieht das beim Einspielen.
